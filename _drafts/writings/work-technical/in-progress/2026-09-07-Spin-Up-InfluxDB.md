Go to timestream for influxDB

| Parameter               | Value                       |
| ----------------------- | --------------------------- |
| InfluxDB Version        | 3                           |

| Instances configuration | Smallest (db.influx.medium) |
| Encryption Key          | AWS Owned Key               |
| subnet                  | private A and private B     |
| Port                    | 8181                        |
| backup                  | Monthly                     |
